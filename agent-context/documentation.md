# Documentação humana para agentes

Produza documentação para pessoas em `README.md`, `docs/` e contratos de API existentes. Não atualize `AGENTS.md` nem `agent-context/` durante uma tarefa normal de documentação; esses arquivos só mudam quando a regra de trabalho dos agentes ou o roteamento de contexto for alterado explicitamente.

Use `README.md` como entrada rápida: propósito, pré-requisitos, instalação, execução, testes e links para `docs/`. Em `docs/`, se aplicável, mantenha documentos separados de arquitetura, desenvolvimento, configuração, operação, API e decisões.

Documente somente comportamento verificável no código, configuração, testes ou contrato. Não invente detalhes: registre lacunas como "Não identificado no repositório" ou um `TODO` com a fonte de validação necessária. Mantenha exemplos seguros e nunca inclua segredos.
